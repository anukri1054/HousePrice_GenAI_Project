# AI-Powered House Price Prediction and Generative AI Insight System

## Project Overview

This project combines Machine Learning and Generative AI to predict house prices and generate intelligent explanations.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Streamlit
* Google Gemini API
* Matplotlib
* Seaborn

## Machine Learning Models

* Linear Regression
* Gradient Boosting Regressor

## Evaluation Metrics

* RMSE
* MAE
* R² Score

## Features

* House Price Prediction
* Model Comparison
* Hyperparameter Tuning
* Cross Validation
* Residual Analysis
* Feature Importance
* Generative AI Analysis

## Run the Project

Install requirements:

`pip install -r requirements.txt`

Train the model:

`python train_model.py`

Run the application:

`streamlit run app.py`
